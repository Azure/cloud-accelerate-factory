## Introduction

  A PowerShell script has been developed to automate the uninstallation of Citrix components and perform Virtual Delivery Agent (VDA) cleanup across multiple Citrix-imaged virtual machines. The script leverages the VDACleanupUtility to ensure comprehensive removal of residual VDA artifacts, enhancing image consistency and reliability for downstream deployment.

## Execution Steps

To remove Citrix components using the provided PowerShell script, follow these steps:

- 📦 **Download** the ZIP file named `Uninstall_Citrix_Components.zip` from this repository 
- 📂 **Extract** the contents of the ZIP file to a folder on your local machine.
- 📁 **Open** the extracted folder.
- 🖱️ **Right-click** on the PowerShell script file named `Uninstall_CTX_Script.ps1`.
- 🛡️ Select **"Run as Administrator"**,Powershell Window will pop up now and Press **Y** button to proceed further
- ✅ The script will begin uninstalling Citrix components automatically.
