# GitHub Migration Factory Offerings 

## Description

This repository contains all migration offerings delivered under the **GitHub Migration Factory** to support enterprise repository migrations from multiple Source Code Management (SCM) platforms to **GitHub Enterprise Cloud (GHEC)**.
   
The **GitHub Migration Factory** provides standardized migration frameworks, execution utilities, automation scripts for performing repository migrations in a controlled and scalable manner. 

This repository includes migration execution utilities that support repository migrations to **GitHub Enterprise Cloud/EMU/Data Residency**

## Migration Offering Scope

The supported migration offerings included:

| Source Platform       | Target Platform                                      |
|-----------------------|------------------------------------------------------|
| Azure DevOps Services | GitHub Enterprise Cloud / EMU / Data Residency       |
| Bitbucket Server      | GitHub Enterprise Cloud / EMU / Data Residency       |
| GitLab Server         | GitHub Enterprise Cloud / EMU / Data Residency       |


This repository serves as a centralized location for migration scripts and pipelines.
